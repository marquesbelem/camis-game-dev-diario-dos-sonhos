# Orientações para o Agente de IA 

- Será uma aplicação mobile first desenvolvida com NextJs.
- Utilize a [camis-game-dev-brand-identity-skill](https://github.com/marquesbelem/camis-game-dev-brand-identity-skill) na abordagem, use como submodulo git submodule add https://github.com/marquesbelem/cami-brand-identity-skill.git .agent/skills/cami-brand-identity.

### Objetivo do Sistema
- Será uma platforma para registro de sonhos seguindo uma escala de clareza, emoção e confirmação abordada no livro sonhos e mediunidade na umbanda rodrigo queiroz.
- A principio pode ser banco de dados local.
- Use o PDF disponivel para pegar informações importantes para fazer a estrutura de dados para o registro https://umbandaead.com.br/wp-content/uploads/2026/01/ebook-diario-dos-sonhos.pdf.
  - o PDF tem a seguinte informação "Esse e-book possui direitos autorais. Estão expressamente proibidas quaisquer outras formas de utilização ou reprodução tais como: editar, adicionar, reduzir e praticar qualquer ato de
comercialização. A violação de quaisquer desses direitos exclusivos do titular, acarretará a sanções previstas na Lei 5988 de 14/12/1973 artigos 184 e 186 do Código Penal e Lei de Direitos Autorais (Lei 9610/1998)." então use o conteudo de um jeito que não vai ferir os direitos, use como orientação. 
- Deixe claro que essa plataforma está sendo baseada no conteudo do livro  sonhos e mediunidade na umbanda rodrigo queiroz.
- Não tenho intuido de comercializar essa plataforma, será free para utilização e aberta parta quem quiser contriibuir com alguma valor para chave Pix. 
- Precisa ter um lugar onde eu possa colocar o link de afilhado do livro.
- Usar mecanismo de SEO para rankear essa plataforma.
